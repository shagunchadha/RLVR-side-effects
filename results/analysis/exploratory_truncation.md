## Heuristic and thresholds

- Compression ratio: `len(zlib.compress(last 3000 characters)) / len(last 3000 characters)` (UTF-8 bytes). Repetitive text compresses well, so a low ratio means a loop.
- Unique 6-gram share: distinct 6-word windows divided by all 6-word windows over the last 400 words. A verbatim loop reuses the same windows, so the share is low.
- **Loop** if compression ratio < 0.25 **and** unique 6-gram share < 0.7. Otherwise **long reasoning cut mid-thought**; **other** if the text already contains `</think>` (none do).
- The thresholds were fixed after looking at these 23 rows. The loop rows and the rest are separated by a wide gap (see the table below: loops have ratio <= 0.204 and share <= 0.565; every other row has ratio >= 0.268 and share >= 0.937), so the classification does not hinge on the exact cut-offs, but they were set post hoc on the same rows they classify.

## Caveat

I read only the **tails** (the last ~220 characters, quoted below) of each row, not the full texts. The loop calls rest on the heuristic plus those tails. For the non-loop rows, "long reasoning cut mid-thought" means: no repetition signature and the tail is mid-sentence reasoning. It does **not** establish that a higher cap would have produced an answer.
